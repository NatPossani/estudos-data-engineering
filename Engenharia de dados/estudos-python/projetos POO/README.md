# Projetos de POO

Exemplos introdutórios de Programação Orientada a Objetos em Python.

## Arquivos

- [musica.py](musica.py): define a classe `Musica`, cria objetos e exibe seus atributos.
- [restaurante.py](restaurante.py): demonstra classe, atributos de instância, atributo de classe e métodos.

## Execução

A partir desta pasta:

```powershell
python musica.py
python restaurante.py
```

Os exemplos usam apenas recursos da biblioteca padrão do Python.
