# Projetos simples

Pequenos programas interativos para praticar entradas, condicionais, laços, funções e números aleatórios.

## Arquivos

- [number-guesser.py](number-guesser.py): jogo de adivinhação de números.
- [quiz.py](quiz.py): quiz sobre hardware e informática, com pontuação final.
- [rock_paper_scissors.py](rock_paper_scissors.py): jogo de pedra, papel e tesoura contra o computador.

## Execução

A partir desta pasta:

```powershell
python number-guesser.py
python quiz.py
python rock_paper_scissors.py
```

Os programas utilizam Python 3 e, quando necessário, o módulo padrão `random`.
