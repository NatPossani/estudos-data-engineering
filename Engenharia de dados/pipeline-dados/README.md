# Pipeline de dados

Projetos práticos de Engenharia de Dados, organizados por pipeline.

## Pipelines

- [pipeline-1](pipeline-1/): pipeline ETL em Python que consulta a API DummyJSON e salva registros de usuários e produtos em arquivos JSON.

Consulte o README dentro de cada pipeline para conhecer suas dependências, configuração e forma de execução.

## Recomendações

- use um ambiente virtual Python;
- não publique credenciais ou dados pessoais;
- mantenha arquivos gerados e artefatos locais fora do versionamento quando apropriado;
- documente a origem dos dados e as limitações de cada pipeline.
